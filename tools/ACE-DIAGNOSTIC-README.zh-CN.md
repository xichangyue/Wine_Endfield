# 终末地 ACE 诊断工具

1. 双击 `终末地ACE诊断.command`。
2. 选择现有的终末地 Mac 安装目录，即包含 `Apps`、`State` 与 `logs` 的文件夹。
3. 完成后 Finder 会选中 `support-日期-进程号.zip`，请只发送这个 ZIP 给维护者。

此工具不安装或清理环境，不启动 Wine、官方启动器或游戏。它会在所选安装目录的 `logs` 中写入一个脱敏支持包，收集固定文件哈希、ACE 服务离线配置、系统摘要和最近五次会话中的相关日志行。账号文件、完整 prefix、游戏资源内容和完整运行日志不会打包；常见凭据字段、用户名、用户主目录和安装路径会被遮盖。

若 macOS 阻止首次双击，可在 Finder 中右键该 `.command` 文件并选择“打开”。
