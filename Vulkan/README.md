# Vulkan

当前优化版：Wine 11.16 → 修改后的 MoltenVK 1.4.2 → Metal，需要 Apple Silicon、macOS 26+ 与 Rosetta 2。

包含本机已验证的同步、资源使用和着色器编译调整；游戏内网页改为 Qt 软件合成，修复测试中出现的残片、色块和错位。网页响应可能稍慢。两种游戏入口共用 `game-profile.sh`，保留实际游玩版本的同步与资源保护配置，不强制改变画质或帧率上限。

新用户建议使用同版本“终末地 Mac 安装器.app”。独立分包也可解压使用：先运行“安装官方启动器.command”选择自己从官网下载的 Windows 安装器，再由官方启动器下载游戏，最后运行“启动游戏.command”。更新游戏前退出游戏，再运行“更新游戏.command”。

包内没有游戏、官方启动器、账号、个人 prefix、微软商业字体或预热缓存。首次着色器编译及新场景卡顿仍可能发生；其他设备和全新安装的完整战斗流程尚未验证。GitHub Source code ZIP 只含源码，不能代替完整运行时包。详细说明和已知限制见仓库根 README。
