# 终末地 Mac 安装器 0.4.0（预发布）

本安装器包含 `0.4.0-preview-20261024` 修复运行库，支持旧版升级、自选安装目录和成功后的自动清理。保留已验证的图形与游戏核心组件，认证组件使用相对路径加载包内 GnuTLS。需要 Apple Silicon、macOS 26 或更新版本及 Rosetta 2；使用者无需安装编译器或 Python。此版未经过 Apple 公证。

## 新安装

1. 打开“终末地 Mac 安装器.app”，选择从官网下载的 Windows 官方启动器 EXE。
2. 选择最终安装文件夹。可以选择内置磁盘，也可以在已连接的移动硬盘中新建一个空文件夹；选择器直接使用所选目录，不会再追加一层目录。
3. 点击安装。安装器只配置运行环境，不自动接受官方协议。首次初始化跳过可选的 Mono/Gecko 下载，避免隐藏对话中断安装；游戏运行时仍使用固定版本配置。完成后，在官方启动器里自行下载和校验游戏。
4. 保留默认游戏下载路径，或选择 `C:\Endfield`；这两个位置均指向安装目录内唯一的 `Game/`。点击官方“开始游戏”游玩。

未勾选官方“DirectX 11启动”使用 Vulkan/MoltenVK；勾选使用 Direct3D 11/DXMT/Metal。启动器本身使用 DXMT，快捷方式不附加渲染参数。

## 从旧版本更新

支持由 v0.2.0、v0.3.0 统一安装器创建、带 `.endfield-installer-v1` 标记的安装，以及此后新版安装。选择原安装文件夹即可；已有官方启动器时不需要重新提供 EXE。

升级前正常退出游戏、官方启动器和其他 Wine 程序。安装器先解压、校验并配置新环境，成功后切换；失败时保留或恢复旧环境。

- `Game/` 和已有 `Launcher/` 保留，游戏无需重新下载；启动器的共享游戏链接会转为相对路径。
- 从已有 `State/` 复制用户环境；第一次从旧版升级优先复制 `Updater/local/`，缺失时依次使用 `DirectX11/local/`、`Vulkan/local/`。不会合并不同旧环境里的图形设置。成功后会删除未采用的旧版设置和缓存，只保留新版正在使用的环境。
- 已有登录数据随环境复制保留，但是否需要重新登录仍由官方启动器决定。
- 原三个模式入口会兼容转到官方启动器。新安装只创建一个“终末地”入口。
- 安装失败时保留或恢复原环境。新版本配置、切换和校验全部成功后，自动清理已识别的旧运行库、旧用户环境和历次 `.runtime-backups/` 中的旧组件，不保留完整旧版用于一键回退。
- 清理属于安装/更新收尾的一部分，无需额外按钮。`Game/`、`Launcher/` 和当前 `State/Recovery/Apps` 不在清理范围；旧目录中若发现实体游戏或删除失败，则保留相应部分，并在成功提示及日志中说明。未采用的旧 Wine 环境及其缓存会整体删除，包括其中自行存放的非游戏文件；已识别清理目录之外的自有文件和未知遗留事务目录保留。
- 旧版固定名称的安装/校验日志及按模式生成的运行日志会一并清理；新版诊断、当前会话日志和根目录中的自定义日志保留。已更新的旧快捷方式仍可使用，不因清理而失效。详情见 `logs/installer-cleanup.log`；若该日志无法写入，主安装日志仍会记录清理失败提醒。

本版不自动接管 v0.1 手工解压包、实验项目目录或其他来源的非空文件夹；请新建安装，或保留原目录等待单独迁移。安装器不覆盖任意未知目录。

## 移动硬盘和搬动

Wine 需要符号链接及可执行文件语义，本安装器只接受 APFS 或 Mac OS 扩展（HFS+）卷；不直接安装到 exFAT、FAT、NTFS 或网络卷，也不会格式化硬盘。苹果确认 APFS 支持外置存储：[磁盘工具格式说明](https://support.apple.com/en-ie/guide/disk-utility/dsku19ed921c/mac)。

运行库、Wine 环境、游戏、日志全部放在所选安装目录；界面安装日志另存于用户 `~/Library/Logs/Wine Endfield Installer/`。连接并解锁外置盘后才能启动，运行或更新时不要拔盘。

如需搬动安装，先退出所有 Wine 进程，再把**整个安装文件夹**复制到另一块受支持的磁盘。随后从新位置的 `Apps/终末地.app` 打开；新版本内部采用相对路径，应用从自身位置定位安装目录，不依赖旧卷名。桌面入口使用 Finder 别名，若复制后的别名仍指向旧目录，可重新在新目录运行安装器创建入口；不会覆盖指向其他安装的同名桌面入口。

旧版目录已经被搬动时，可以在新位置升级。安装器会参考其原应用记录识别旧的共享游戏映射，转为相对路径；如果映射指向无法确认的其他位置，会停止并保留原文件。

## 验证与日志

```bash
bash installer/test-installation.sh /完整安装目录
```

安装目录的 `run.sh --check` 也是只读检查，不启动游戏。安装包保留完整运行库校验及核心组件校验。运行日志在 `logs/`；普通运行保留最近五个已结束/新建会话。安装日志用于排查失败；关闭观察终端不会提供强制结束游戏的功能。

安装失败时，弹窗会显示失败阶段、退出码和错误摘要；“查看日志”可定位完整安装日志。主日志记录系统版本、架构和安装器版本，并收录失败步骤的详细日志末尾，避免只有“可在同一目录重试”的提示。详细校验、官方 EXE 解压和 Wine 初始化日志仍保存在安装目录 `logs/installer-verify.log`、`installer-extract.log`、`installer-prefix.log`。

若反馈的是 GitHub 上的 v0.3 旧版，请提供原安装目录 `logs/installer-*.log` 的末尾；若只显示正在配置环境，还需对应 `setup-Vulkan.log`、`setup-DirectX11.log` 或 `setup-updater.log` 的末尾，以及芯片型号、完整 macOS 版本和安装磁盘格式。旧版通用“安装未完成”弹窗不能确定原因，用户侧安装不执行源码编译。新版已调整首次可选组件下载、异常中断后的锁和搬动后的路径处理，但不代表每一例旧版失败都来自这些问题。

当前兼容性来自本机固定修复版本；资源下载期间曾有局部画面异常。安装器验证范围和未测试项目见仓库 `VALIDATION.md`。固定运行库不会阻止官方启动器或游戏更新。

## 构建

```bash
bash tools/package-recovery.sh /固定版本目录 /新的payload输出目录 v0.4.0-preview
bash tools/build-installer.sh /payload输出目录 /新的安装器输出目录 v0.4.0-preview
```

构建需要 Xcode Command Line Tools。安装器不携带官方 EXE、游戏、prefix、账号或个人缓存。源码和许可边界见 `THIRD_PARTY.md` 及 payload 的 `PACKAGE-NOTICE.txt`；对应的修改后 Wine、MoltenVK 源码及其他组件来源随 Release 提供；复用运行库无需在用户机器上编译。
