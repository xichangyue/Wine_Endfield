# 统一安装器（v0.2.0-preview 实验版）

下载 [GitHub Release](https://github.com/xichangyue/Wine_Endfield/releases/tag/v0.2.0-preview) 中的 `Wine_Endfield-Installer-0.2.0-preview.zip`，解压后打开应用。此附件保持本机测试过的构建，内嵌说明中的“本地预览”代表同一版本，不影响使用。

这是原生 macOS 安装向导，内含两套 v0.1.0 预编译运行时，不需要安装编译器。系统最低版本声明不代表游戏在该版本已测试；当前仍只验证作者 M1 Max / macOS 26.6.1。

1. 打开“终末地 Mac 安装器.app”，选择自己从官网下载的 Windows 官方启动器 EXE（当前只验证 1.5.0 安装包）。
2. 选择安装位置和 Vulkan、DirectX11 或两者；点击安装。系统需要 Rosetta 2。安装器不会覆盖非本项目管理的已有目录。
3. 完成后自动打开官方启动器。自行确认协议，保留默认游戏目录，或选择 `C:\Endfield`。不要选择其他目录，否则共享映射不会自动跟随。
4. 等官方启动器下载、解压和校验完毕后退出。用桌面对应渲染方式的入口游玩，不使用官方“开始游戏”。本安装器不宣称已完成游戏安装，也不自动判断下载完成。

游戏只保存在安装目录的 `Game/` 一份。`Vulkan/`、`DirectX11/` 和独立 `Updater/` 分别保存环境；所选模式和官方启动器均映射到共享目录。两模式配置及缓存保持独立。单选 Vulkan 时官方启动器使用软件渲染。

## 大版本更新

先正常退出游戏，再使用“终末地 更新与修复”入口，由官方启动器更新并校验共享目录，然后退出。两种模式直接读取相同的新文件，不复制、不重复下载。项目入口使用文件锁防止游戏和更新重叠；手工直接运行 Wine 或 EXE 绕过入口不在此保护范围。

入口实际保存在安装目录 `Apps/`，桌面是链接。不要移动或删除安装目录。已有同名桌面入口不会覆盖。安装中断可在同一路径重试，保留 `logs/` 排查；不自动删除游戏、缓存或旧数据。

安装器不是兼容层自动升级工具，不替换已有 v0.1.0 手动安装，也不承诺游戏更新后兼容性不变。当前使用固定校验的 v0.1.0 运行时。官方下载内容、登录和游戏内操作仍由用户完成。免费、未公证，遵循 macOS 安全提示，不应关闭全局安全保护。

## 构建

下载 v0.1.0 Release 两个完整 tar.xz 后执行：

```bash
bash tools/build-installer.sh /存放两个完整包的目录 /新的输出目录
```

构建需 Xcode Command Line Tools。Wine 等依赖的源码和许可继续见根目录 THIRD_PARTY.md 与 v0.1.0 Release 附件；原运行时包及许可原样内嵌。不包含官方安装器、游戏、账号、缓存或微软字体。
