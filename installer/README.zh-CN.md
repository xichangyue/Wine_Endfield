# 统一安装器（v0.3.0-preview）

下载 [GitHub Release](https://github.com/xichangyue/Wine_Endfield/releases/tag/v0.3.0-preview) 中的 `Wine_Endfield-Installer-0.3.0-preview.zip`，解压后打开“终末地 Mac 安装器.app”。内含本次发布的 Vulkan 与 DirectX11 预编译运行时，使用者无需安装编译器。

需要 Apple Silicon、macOS 26 或更新版本，以及 Rosetta 2。当前游戏测试主要来自作者的 M1 Max；不代表所有系统版本及机型均已验证。安装器不会代用户接受系统、游戏或官方启动器协议。

1. 选择自己从官网下载的 Windows 官方启动器 EXE。安装器会识别包含 `Launcher.exe` 与 `Games.exe` 的唯一版本目录，不固定版本路径。原流程曾验证官方 1.5.0；本次动态目录识别另以 synthetic 布局测试，未据此宣称所有新版官方安装包均已实测。
2. 选择安装位置及 Vulkan、DirectX11 或两者，点击安装。安装器拒绝覆盖不由本安装器管理的已有目录；安装或升级前请退出全部 Wine 游戏、网页与启动器进程。
3. 配置完成后自动打开官方启动器。自行确认协议，保留默认游戏目录，或选择 `C:\Endfield`。不要选择其他位置，否则共享映射不会自动跟随。
4. 等官方启动器下载、解压和校验游戏后退出，再使用对应渲染方式的快捷方式游玩。不要使用官方“开始游戏”按钮。

“环境安装完成”不代表游戏下载完成。本安装器不显示游戏下载进度，也不自动判断下载完成。免费、未公证；请核对 Release 中的 SHA-256，并遵循 macOS 安全提示。

## 本版运行配置

Vulkan 入口与独立运行时包使用同一份 `game-profile.sh` 配置，包含当前优化过的 Wine/MSync、MoltenVK 运行时及网页 Qt 软件合成设置。网页响应可能略慢；已完成显示、导航、关闭以及返回游戏的本机测试。DirectX11 保留此前的 Wine/DXMT 运行时，不宣称获得同样的 Vulkan 性能改进。

游戏只保存在安装目录 `Game/` 一份。`Vulkan/local/`、`DirectX11/local/` 和独立 `Updater/local/` 分别保存 Wine 环境；所选模式及官方启动器都映射到共享游戏目录。渲染配置、prefix 和缓存保持独立。

## 已有安装与游戏更新

使用过 v0.2.0 统一安装器的用户，可选择原来的受管理安装目录升级。安装器校验内嵌资源清单、压缩包 SHA-256 及运行时内部校验文件后，才暂存并替换所选运行时；保留 `local/` 中的 prefix、缓存及配置，以及 `Game/`、`Launcher/`、`Updater/`。相同 payload 再安装会保留现有环境。替换或配置失败时自动恢复原运行时；失败的新安装保留已创建的 local 环境以便重试。

成功升级时，旧运行时及其目录内的额外文件保存在 `.runtime-backups/`，不自动清理。此备份不包含已转移到当前版本的 `local/`，不是独立可启动的完整备份。确认新版本可用后可自行检查并删除。不迁移 v0.1.0 的手动解压安装，也不覆盖任意其他已有目录。

游戏大版本更新请先正常退出游戏，使用“终末地 更新与修复”入口，由官方启动器更新并校验共享目录，再退出启动器。两种模式读取同一份新文件，无需重复下载。应用入口通过文件锁阻止安装、游戏及更新重叠；手工直接运行 Wine 或 EXE 绕过入口不在此保护范围。

应用实际位于安装目录 `Apps/`，桌面只是链接。不要移动或删除安装目录。已有同名桌面入口不会被覆盖，请使用原安装目录下的入口，或检查桌面链接是否指向目标目录。保留 `logs/` 可用于排查失败。

## 构建

准备同一标签的两个完整运行时包后执行：

```bash
bash tools/build-installer.sh /存放两个完整包的目录 /新的输出目录 v0.3.0-preview
```

构建需 Xcode Command Line Tools。脚本从实际复制进应用的 payload 生成 `payload-manifest.tsv`，包含版本、文件名及 SHA-256；不手工填写新包的散列值。应用以本次编译目标 macOS 26 声明最低版本，安装前也检查系统版本。独立安装后可运行 `bash installer/test-installation.sh /安装目录` 校验结构、映射、运行时及入口签名。

源码和许可见根目录 `THIRD_PARTY.md`、`BUILD.zh-CN.md` 及 Release 附件。不包含官方安装器、游戏、用户账号、prefix、缓存或微软字体。Wine 及其他组件保持各自许可；独立安装器代码使用 MIT 许可。
