# v0.3.0-preview：当前优化版与统一安装器

下载 `Wine_Endfield-Installer-0.3.0-preview.zip`，解压后打开“终末地 Mac 安装器.app”。安装器内含本标签的 Vulkan 与 DirectX11 预编译运行时，使用者无需编译。

Vulkan 入口同步当前测试版的 Wine/MSync 与 MoltenVK 配置，并使用 Qt 软件合成修复内嵌网页的文字残片、色块及错位。用户已确认本机网页首页、导航切换、关闭及返回游戏均正常，轻微网页响应延迟暂予保留。DirectX11 继续分发原有 Wine/DXMT 运行时，不宣称同步获得 Vulkan 的性能改善。

## 安装与升级

1. 需要 Apple Silicon、macOS 26 或更新版本、Rosetta 2。提供自行从官网下载的 Windows 官方启动器 EXE，选择安装位置及渲染方式。
2. 安装器配置各自独立的 Wine 环境、共享 `Game/` 目录及桌面入口，然后打开官方启动器。自行确认协议并下载、解压、校验游戏；保留默认目录或选择 `C:\Endfield`。
3. 完成后退出官方启动器，从对应渲染方式的快捷方式游玩，不使用官方“开始游戏”按钮。
4. 游戏更新使用“终末地 更新与修复”；两种模式共用游戏文件，更新一次即可。

v0.2.0 统一安装器创建的受管理目录可原地升级。新安装器由构建时生成的清单校验当前 payload，先暂存新运行时，再保留 prefix、缓存及游戏文件进行替换；配置失败时恢复原运行时。成功升级保留 `.runtime-backups/` 中的旧运行时及额外文件，不自动删除。此备份不包含已转移到当前版本的 local 状态。其他已有目录及 v0.1.0 手动安装不会被自动迁移或覆盖。

官方安装器仍需用户提供，不随包分发。原流程曾验证 1.5.0；本次提取过程改为识别唯一官方版本目录，以 synthetic 布局验证动态识别，不宣称已实测所有新版官方包。不代用户接受协议，也不将“环境安装完成”当作游戏下载完成。

## 验证范围与限制

资源校验、Swift 编译、安装结构及更新保护的具体验证结果见本标签发布说明。游戏与网页测试来自当前本机优化环境；全新环境的完整游戏下载、长时间战斗、所有机型及后续游戏更新不作保证。首次 shader 缓存预热和进入新场景仍可能出现卡顿。

独立应用入口位于安装目录 `Apps/`，桌面为链接。已有同名入口不会被覆盖。免费、未公证；请校对 Release 中的 SHA-256 并遵循系统安全提示。
