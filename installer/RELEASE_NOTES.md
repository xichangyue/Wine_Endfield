# v0.2.0-preview：统一 Mac 安装器

下载 **Wine_Endfield-Installer-0.2.0-preview.zip**（约 429 MiB），解压后打开“终末地 Mac 安装器.app”。不需要编译器；应用内含两套已编译运行时。保留经过本机测试的原构建，未修改图形兼容层。

## 安装与使用

1. 自行从游戏官网下载 Windows 官方启动器 EXE，交给安装器（目前验证官方 1.5.0 安装包）。
2. 选择安装位置，勾选 Vulkan、DirectX11 或两者。安装器配置独立 Wine 环境、共享游戏目录及桌面入口。
3. 环境配置完成后打开官方启动器，自行确认协议并下载、解压和校验游戏。保留默认下载位置，或选择 `C:\Endfield`。
4. 退出官方启动器，从对应渲染方式的快捷方式游玩。**不要使用官方“开始游戏”按钮。**

“环境安装完成”不代表游戏下载完成。本安装器不显示游戏下载进度、不自动判定下载完成，也不代替用户接受协议。

## 更新与共用游戏

- 使用“终末地 更新与修复”进行大版本更新和校验。两种模式共用一份 Game 目录，更新一次，无需同步复制。
- 各模式配置和缓存独立。项目入口阻止更新与游戏同时运行；手工绕开入口不在保护范围。
- 桌面是链接，实际应用在安装目录 Apps/ 下。已有同名桌面入口不会覆盖，请直接使用新安装目录中的 Apps。
- 不会迁移或覆盖旧 v0.1.0 手动安装。兼容层自动升级不属于本版功能。

## 测试与限制

三种模式选择均通过本机新环境初始化、共享路径和生成应用检查；重复安装、桌面创建、缺少游戏提示与更新互斥已测试。用户也试用了默认安装流程并确认体验正常。未重新下载完整游戏，尚未验证新安装环境的完整战斗流程或实际大版本更新。

需要 Apple Silicon、Rosetta 2；当前仅在 M1 Max / macOS 26.6.1 验证。免费、未公证；请核对 SHA-256 并遵循系统安全提示，不要关闭全局安全保护。字体回退、首次缓存预热及游戏后续更新的兼容性限制仍存在，不保证账号安全或所有机型可玩。
