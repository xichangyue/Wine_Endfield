# v0.4.0-preview：启动修复、旧版升级、自动清理与移动硬盘安装

本版恢复通过官方启动器进入游戏，增加旧版原地升级、安装路径选择和成功后的自动清理。

推荐下载 **Wine_Endfield-Installer-0.4.0-preview.zip**（约251 MiB）。解压后打开“终末地 Mac 安装器.app”。需要 Apple Silicon、macOS 26+、Rosetta 2；无需 Xcode、编译器或 Python。GitHub 自动生成的 Source code ZIP 不含可直接使用的安装器。

## 从 v0.2 / v0.3 原地升级

1. 正常退出游戏、官方启动器及其他 Wine 程序；若安装在移动硬盘，先连接并解锁磁盘。
2. 打开新版安装器，选择**原来的安装根目录**。例如 `~/Games/Wine Endfield`，该目录内通常有 `Game`、`Launcher`、`Apps`、`Vulkan` 或 `DirectX11`。不要选 `Game`、某个渲染模式子目录或安装器 App 本身。
3. 原目录已有 `Launcher/Launcher.exe` 时，官方 EXE 一栏可留空。旧版安装中途失败、尚未生成官方启动器时，需要再次选择从官网下载的 Windows 官方启动器 EXE。
4. 点击“更新环境并打开官方启动器”，等待完成。无需删除旧运行库、游戏、prefix、缓存或旧 `.setup-lock`。若界面判断不是受管理目录，请核对路径，不要手工创建安装标记。
5. 升级完成后，使用新的“终末地”入口，**通过官方启动器的“开始游戏”游玩**。原先 Vulkan、DX11、更新与修复三个入口会兼容转到官方启动器，名称不再强制游戏渲染模式。

**保留哪些内容：** 共享 `Game/`、已有 `Launcher/` 保留；已有新式 `State/` 优先复制，否则先复制旧 `Updater/local/`，再依次回退到 `DirectX11/local/`、`Vulkan/local/`。不同旧环境的设置不会自动合并，官方可能要求重新登录。新环境配置、切换和校验全部成功后，自动清理已识别的旧 `Vulkan/DirectX11/Updater` 运行库、旧设置和缓存，以及历次运行库备份，只保留新版实际采用的用户环境。没有额外清理按钮，也不再保留完整旧环境用于一键回退。安装失败时不执行这项清理，旧环境用于恢复。安装器无需重新下载整份游戏，但官方启动器仍可能按游戏版本执行正常更新和校验。

**旧安装失败也能重试：** 只要原目录由 v0.2/v0.3 安装器创建且仍有 `.endfield-installer-v1` 标记，即可选回原目录修复。仅解压过旧安装器、未形成受管理目录的情况，请按新安装选择空目录。本版不自动接管 v0.1 手工解压分包或其他来源的环境。

**游戏文件保护：** 当前 `Game/`、`Launcher/` 和新版用户环境不会被删除。若旧目录中混有真实 `Endfield.exe`、`Endfield_Data` 等游戏内容，会保留该部分。未采用的旧 Wine 环境和缓存会整体删除，包括其中自行存放的非游戏文件；已识别清理目录之外的自有文件保留。清理异常不会回滚已经安装成功的新环境，而是在完成提示中告知，并记录到主安装日志及可写入的 `logs/installer-cleanup.log`。未知 `.setup-work.*` 失败现场不会被一概删除。

旧版固定名称的安装/校验日志和按模式生成的运行日志也会自动清理。新版诊断、当前会话和根目录中的自定义日志保留；旧快捷方式已更新为统一入口，继续可用。

## 游戏渲染方式

- 官方“DirectX 11 启动”**未勾选**：Vulkan → MoltenVK → Metal。
- 官方“DirectX 11 启动”**勾选**：Direct3D 11 → DXMT → Metal。

入口不添加强制渲染参数。启动器界面自身使用 DXMT，与游戏的渲染选择分别处理。旧版“不要点击官方开始游戏”的说明不再适用。

## 新安装与移动硬盘

新用户选择空目录，提供官网 Windows 官方启动器 EXE；配置完成后，在官方启动器自行确认协议并下载游戏。使用默认下载位置或 `C:\Endfield`。

可以指定内置磁盘或 APFS / Mac OS 扩展（HFS+）外置盘上的目录。exFAT、FAT、NTFS、网络卷和未挂载磁盘会被明确拒绝，不会格式化磁盘。安装、游戏与更新过程中保持磁盘连接。

已有安装如需换盘，先退出 Wine，再把**整个安装目录**移动到受支持的磁盘，从新位置 `Apps/终末地.app` 启动。升级时改选另一空目录不会自动迁移旧游戏。内部映射改为相对路径，App 从自身位置定位安装；桌面已有同名的其他安装入口不会被覆盖。搬动后若官方启动器未识别游戏，先用其定位/校验功能指向 `C:\Endfield` 的已有资源，避免重复下载。

## 本版改动

- 固定本机已成功进入游戏的 Wine 兼容修复，统一运行库与官方启动器入口。
- 官方启动器使用已验证的 DXMT 路径，处理此前的白屏问题。
- 初次 Wine 初始化跳过不需要的 Mono/Gecko 下载对话；游戏运行时保留原验证配置。
- 安装与运行共用系统文件锁，避免旧目录锁在异常中断后阻止重试。
- 安装失败显示阶段、退出码和原始错误摘要，主日志汇入失败步骤的详细输出。
- 认证组件改为相对路径加载随包 GnuTLS，消除对开发机目录的依赖；新安装和搬动目录后的离线 TLS 初始化已验证。
- 升级先准备副本再切换；普通失败路径保留或恢复旧环境，成功后自动清理旧版本残留与未采用的设置/缓存。

## 若仍然安装失败

点击安装器“查看日志”，提供末尾约30行，并注明芯片型号、完整 macOS 版本、安装位置与磁盘格式。主日志位于 `~/Library/Logs/Wine Endfield Installer/`；分步骤日志位于安装目录 `logs/installer-prefix.log`、`installer-extract.log` 或 `installer-verify.log`。分享前去掉账号等个人信息，不要上传整个 Wine prefix。

旧版反馈“mac 27.2、安装未完成”尚未取得具体日志，不能宣称已定位或解决该设备问题；这句话本身是通用安装失败提示，不是编译器报错，也不足以证明系统版本不兼容。

## 验证与限制

本机 M1 Max / macOS 26.6.1 完成真实全新安装、早期 v0.2 安装副本升级、已公开 v0.3 运行包与旧 prefix 构造目录的升级、同版重装和目录搬动；自动清理及游戏文件保留检查通过，原安装的17653项文件、链接与目录清单未变。新安装和搬动后的离线 TLS 探针均通过。65项模拟集成检查覆盖失败回滚、重复清理和收尾故障；此前14项错误摘要测试及原生入口、界面验证通过。实体移动硬盘跨卷/拔插、其他 Mac、该反馈者设备及所有游戏场景未完成同等验证，资源下载时仍可能出现局部画面异常；不保证固定帧率。

此版为预发布、临时签名且未经过 Apple 公证。独立安装器和运行包不包含游戏、官方安装器、账号或个人缓存。同一 Release 提供完整修改后 Wine 源码及模块变体、MoltenVK 源码、上游 DXMT/7-Zip 源码和校验文件。请同时保留许可与对应源码，详见仓库 THIRD_PARTY.md、BUILD.zh-CN.md 和 VALIDATION.md。

新版安装器还在现有游戏的独立克隆副本中实测：通过官方启动器进入游戏，使用者确认画面正常，随后反馈游玩卡顿，原因尚未确定。该测试保留了原用户环境和已有 Vulkan 缓存，不能简单归因于没有缓存；原日常环境未替换。
