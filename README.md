# Wine_Endfield
arm mac的《明日方舟：终末地》兼容层

### 图形实现
- DirectX 11
- Vulkan
两种渲染方式都做了实现，在作者电脑测试游玩基本无问题。

### 注意事项
1.作者只在M1Max的Mac中进行了测试，系统为macOS26.6.1，不保证其他主机可用。   
2.因为反作弊的原因，又因为本项目使用wine模拟作为实现方式，所以不保证账号安全，可能有封号风险（虽然作者一直拿这个玩）。   
3.理论讲Vulkan版本会更流畅，但需要有缓存后才会流畅，初次游玩时应该会很卡，但需要适应一段时间后才会流畅；DirectX 11版本一直相对流畅，但性能上限不及Vulkan版本。   
4.输入映射的是windows的输入方式，需要自行适应，由于作者使用的就是windows版键盘所以无障碍。

## 下载与启动（简体中文）

优先下载本仓库 **Releases** 中的预编译安装包，不要把 GitHub 自动生成的 Source code ZIP 当成安装包。

| 安装包目录 | 渲染路径 | 当前实测情况 |
| --- | --- | --- |
| Vulkan | Wine Vulkan → MoltenVK 1.4.2 → Metal | 本机缓存预热后游玩较流畅；首次技能和场景可能卡顿 |
| DirectX11 | Direct3D 11 → DXMT 0.80 → Metal | 双缓冲改善视角响应；短时间大量技能仍可能卡顿 |

这是实验性预发布，不保证所有 Mac、系统版本或后续游戏更新均可用。“性能上限”等描述仅是作者本机体验，不是跨设备基准结论。本机实测系统版本为 **macOS 26.6.1**（上方旧记录存在笔误），设备为 M1 Max。

### 直接使用预编译 Release

1. 下载对应的 `Wine_Endfield-Vulkan-*.tar.xz` 或 `Wine_Endfield-DirectX11-*.tar.xz`，用 macOS 归档实用工具解压到自己的可写目录。两个文件夹分别管理，不要改名；也不要合并两套 runtime 或 local 目录。
2. 需要 Apple Silicon Mac 与 Rosetta 2。如系统提示安装 Rosetta，按 Apple 提示安装。包内已包含编译好的 Wine 及图形组件，正常使用无需安装编译器或再次下载 Wine。
3. 自行通过官方渠道安装/准备 Windows PC 版游戏。双击目录中的 **启动游戏.command**；首次会校验运行时并创建全新的 Wine 用户目录，请耐心等待。
4. 在终端提示中粘贴**包含 Endfield.exe 的游戏目录绝对路径**。不要加引号，不要把空格写成反斜杠转义。中文及空格路径可以使用。该路径会映射为 `C:\Endfield`。
5. 自行登录游戏。Vulkan 默认使用已实测的同步提交、禁用 Metal heap、关闭验证层配置；DX11 默认使用双缓冲。不会强制降低分辨率、画质或锁定 60 帧。两个版本的游戏设置和缓存相互独立，需分别设置。
6. 先正常退出当前游戏，再启动另一版本。首次大世界/技能缓存尚未预热，不能与已预热环境直接比较。

如果 macOS 阻止未公证程序，请确认来源、比对 Release 的 SHA256SUMS.txt，再按系统“隐私与安全性”的提示处理。不要关闭整个系统的安全保护。具体 macOS 兼容范围尚未在其他设备测试。

### 更新、安装与校验游戏

两个版本可以指向同一份游戏文件，更新一次即可。请先退出所有游戏进程，再双击 **更新游戏.command**，按提示填写自己下载的官方 `Launcher.exe` 路径。

优先使用 **DirectX11** 包的更新入口；其官方启动器使用 DXMT。Vulkan 包的更新入口使用软件渲染，性能可能较差，尚未验证完整下载流程。首次安装游戏可先运行更新入口，在官方启动器中安装到自己选择的位置，之后把实际游戏目录提供给“启动游戏”。

已有游戏可在官方启动器中定位实际游戏目录（建立映射后也可用 `C:\Endfield`）。完成更新/校验后退出官方启动器，**通过本包“启动游戏.command”游玩，不要点击官方启动器的“开始游戏”**：本项目没有把官方勾选项整合成两种模式切换。

### 故障处理与自行编译

- 启动日志位于各自 `local/logs/`。分享日志前请删除账号、设备标识、用户目录等隐私信息。
- `local/prefix/` 保存登录状态、配置和缓存，更新发行包时请先备份；不要公开上传。不要把作者的 prefix 或别人的缓存当作必要组件。
- 游戏目录移动后，请在确认游戏退出后修正 `local/prefix/drive_c/Endfield` 符号链接；不要删除它指向的游戏目录。
- 本包不包含游戏本体、官方启动器、账号、微软商业字体或预热缓存。中文字体使用系统字体回退，不能保证与作者安装的自有 Windows 字体完全相同。
- 预编译包无法运行时，请先保存错误，再参考 **[自行编译教程](BUILD.zh-CN.md)**。自行编译并不保证解决游戏反作弊或驱动兼容问题。
