# DirectX11

独立管理的 Direct3D 11 → DXMT 0.80 → Metal（双缓冲） 实验版本。

下载 Release 完整预编译包后解压。新用户先从游戏官网下载启动器安装器 EXE，双击“安装官方启动器.command”选择该安装器；脚本提取原始启动器文件后打开官方启动器，由用户确认协议并下载游戏。下载完成后运行“启动游戏.command”，优先自动识别游戏目录。无需编译或下载 Wine。无游戏本体、账号、微软字体或预热缓存。Git 源码目录不含 runtime 编译产物。

“更新游戏.command”用于打开自己的官方 Launcher.exe。优先使用 DirectX11 包的更新入口；Vulkan 包的启动器使用软件渲染，尚未验证同等流畅性。更新完成后退出启动器，再用本包启动游戏。详细限制及启动步骤见仓库根 README。
